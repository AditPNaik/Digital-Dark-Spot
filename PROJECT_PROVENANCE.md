# Project provenance and verification

Most source files in this archive were recovered from the user-provided **Digital Dark Spot Architecture.docx** export, which contains Gemini Phase 2–12 code listings. Files absent from that export but needed for packaging (Dockerfiles, Tailwind/PostCSS configs, package marker files) were reconstructed as minimal configuration.

The export itself contains a mixture of complete code listings and narrative claims. This archive does not assume that every claimed feature is production-ready. Run the verification steps in README.md on your machine. API-backed research requires your own Gemini and Tavily API keys. Never commit `.env`.
